📊 WHAT THE SYSTEM DOES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Input: Presidential advisor Q&A data (CSV)
   ↓
Load & Prepare
   ↓
Generate Responses (using Ollama/Llama3)
   ↓
Score Responses (8-dimensional reward function)
   ├─ Relevance (question-answer overlap)
   ├─ Depth (response length)
   ├─ Leadership (quality keywords)
   ├─ Policy Knowledge (governance understanding)
   ├─ Balance (nuanced perspectives)
   ├─ Quality Signals (avoids uncertainty)
   ├─ Reference Match (vs ideal response)
   └─ Structure (sentence count)
   ↓
Create Training Artifacts
   ├─ JSONL format (for fine-tuning)
   ├─ Ollama Modelfile (for creation)
   └─ JSON Report (detailed analytics)
   ↓
Output: Deployment-ready files
